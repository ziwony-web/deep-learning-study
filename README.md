## How to read this archive

- **Foundations:** tensor operations → model training → CNN → sequence models.
- **Computer vision:** residual learning → object detection → vision Transformers → contrastive representation learning.
- **Evidence:** Markdown explanations, linked notes, and presentation PDFs. Code snippets inside notes are learning examples; no standalone training experiments or benchmark reproductions are currently packaged here.
